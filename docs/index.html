Comprehensive Taxonomy

Expert Slimming vs. Expert Trimming

A principled taxonomy spanning intra-expert weight modifications to macro-level structural module drops.

Expert Slimming

Intra-Expert Pruning

Prunes non-critical weights within expert matrices via Magnitude, Wanda, or SparseGPT. Preserves routing topology while reducing parameters.

Wanda / SparseGPT Intra-Expert
Expert Slimming

4-bit Quantization

Applies AWQ or GPTQ to quantize expert weights to 4-bit representation, reducing memory footprint by ~75% with high inference acceleration.

AWQ & GPTQ 75% VRAM Reduction
Expert Trimming

Expert Drop

Reduces total number of candidate experts in each MoE router based on routing frequency and contribution, cutting parameter size and cross-GPU All-to-All communication.

Comm. Reduction Router-Level
Expert Trimming

Layer & Block Drop

Aggressively drops entire attention layers, MoE feed-forward layers, or whole Transformer blocks where representational similarity between layers is high.

Getting Started

Quick Installation & Usage

Run MoE compression and evaluation pipelines in minutes.

# 1. Environment Setup
git clone https://github.com/CASE-Lab-UMD/Unified-MoE-Compression.git
cd Unified-MoE-Compression
pip install -e .
pip install flash-attn --no-build-isolation

# 2. Run Expert Trimming (Expert Drop / Layer Drop / Block Drop)
bash scripts/compression/expert_drop/mixtral_expert_drop.sh
bash scripts/compression/layer_drop/mixtral_layer_drop.sh

# 3. Run Post-Training 4-bit Quantization
bash scripts/compression/quantization/awq.sh

# 4. Evaluate FLOPs, Speed, and Benchmarks
bash scripts/evaluation/speedup/measure_speed.sh
bash scripts/evaluation/benchmark/run_benchmark.sh
