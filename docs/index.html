Intra-Expert Slimming

Individual expert matrices exhibit substantial weight-level redundancy. Applying 4-bit Post-Training Quantization (AWQ/GPTQ) achieves near-lossless accuracy while cutting memory by ~75%.

2

Structural Trimming

Rather than fine-grained weights, macro components (infrequently routed experts, redundant layers, or entire Transformer blocks) can be eliminated entirely, yielding immediate hardware speedups.

Unified Pareto Recipes

By orchestrating Structural Trimming → 4-bit Quantization → Lightweight Post-Finetuning, practitioners attain the optimal Pareto trade-off between model reasoning and serving latency.

Unified Framework

MoE Compression Taxonomy

Explore the multi-dimensional landscape of compression methods spanning intra-expert weight modifications, structural drops, and compound recipes.

Weight Pruning Intra-Expert

Magnitude, Wanda & SparseGPT

Prunes fine-grained individual weight elements inside each expert matrix according to weight magnitude or input-activation-weighted saliency scores (W · X).

Routing Preservation: 100% Preserved
Memory Footprint: Moderate (~30-50% with sparse storage)
Hardware Speedup: Requires 2:4 / Sparse Kernels
Quantization Low Bitwidth

4-Bit Post-Training Quantization (AWQ / GPTQ)

Quantizes full-precision expert parameters to INT4/FP4 representations. Activation-aware Weight Quantization (AWQ) protects top 1% salient weights to prevent perplexity spikes.

Memory Footprint: ~75% VRAM Reduction (4-bit)
Speedup: 2.05× on Ampere/Ada/Hopper
Zero-Shot Degradation: < 0.8% across MMLU/GSM8K
Router Level Expert Drop

Expert Drop

Ranks expert utilization across calibration samples and removes low-frequency / low-contribution experts, directly resizing router dispatch matrices.

  • Directly reduces expert parameters by 25-50%
  • Slashes distributed All-to-All communication traffic
  • Maintains top-k routing among preserved experts
Sublayer Level Layer Drop

Layer Drop

Selectively drops entire Self-Attention sublayers or MoE Feed-Forward sublayers in intermediate stages where cosine representational distance is minimal.

  • Cuts layer forward computation directly
  • Reduces model depth and sequential latency
  • Zero custom kernel dependencies
Full Block Level Block Drop

Block Drop

Eliminates contiguous full Transformer blocks (Self-Attention + MoE FFN + LayerNorms) based on input-output identity similarity scores.

  • Maximal latency speedup per dropped parameter
  • Substantial KV-cache memory saving
  • Fully supported by all standard inference engines (vLLM, SGLang)
Compound Compression Pipeline

Reproducible Codebase

Quickstart & CLI Workflows

End-to-end execution pipelines for structural trimming, intra-expert slimming, lightweight recovery finetuning, and LM-Evaluation-Harness benchmarking.

Install dependencies with PyTorch 2.1+ and Flash-Attention 2 
# 1. Clone the repository
git clone https://github.com/case-lab-umd/Unified-MoE-Compression.git
cd Unified-MoE-Compression

# 2. Create and activate a conda environment
conda create -n moe-compress python=3.10 -y
conda activate moe-compress

# 3. Install core dependencies
pip install -r requirements.txt

# 4. (Optional) Install Flash-Attention 2 for accelerated training & evaluation
pip install flash-attn --no-build-isolation
Structural Expert Dropping and Layer Dropping scripts 
# Structural Expert Drop on Mixtral-8x7B (Retain top-6 out of 8 experts per layer)
bash scripts/compression/expert_drop/mixtral_expert_drop.sh     --model_path mistralai/Mixtral-8x7B-v0.1     --preserve_n 6     --save_path ./compressed_models/mixtral_expert_drop_6

# Layer Dropping (Prune 4 non-critical MoE layers based on router entropy)
bash scripts/compression/layer_drop/mixtral_layer_drop.sh     --model_path mistralai/Mixtral-8x7B-v0.1     --drop_layers 4     --save_path ./compressed_models/mixtral_layer_drop_4
AWQ / GPTQ Quantization and Wanda / SparseGPT Pruning 
# 4-bit AWQ Quantization (W4A16 with activation-aware scaling)
python -m src.compression.quantize_awq     --model_path ./compressed_models/mixtral_expert_drop_6     --w_bit 4     --q_group_size 128     --save_path ./compressed_models/mixtral_exp6_awq4bit

# 50% Wanda Structured Intra-Expert Pruning
python -m src.compression.prune_wanda     --model_path mistralai/Mixtral-8x7B-v0.1     --sparsity_ratio 0.5     --save_path ./compressed_models/mixtral_wanda_50
Parameter-Efficient LoRA Recovery Finetuning (DeepSpeed-MoE ZeRO-3) 
# Recovery Finetuning with LoRA (250 steps on UltraChat / SlimPajama)
deepspeed --num_gpus=8 scripts/finetuning/run_moe_finetune.py     --model_path ./compressed_models/mixtral_exp6_awq4bit     --dataset_name HuggingFaceH4/ultrachat_200k     --lora_r 64     --lora_alpha 128     --max_steps 250     --learning_rate 2e-5     --deepspeed_config configs/zero3_moe.json     --output_dir ./checkpoints/mixtral_recovered
Automated LM-Evaluation-Harness across standard academic benchmarks 
# Run LM-Eval Harness on compressed checkpoint across all benchmark tasks
lm_eval --model hf     --model_args pretrained=./compressed_models/mixtral_exp6_awq4bit     --tasks mmlu,gsm8k,arc_challenge,winogrande,hellaswag     --batch_size 16     --device cuda:0     --output_path ./eval_results/mixtral_unified_recipe.json
